# 部署后核验方案（待用户另行授权部署）

本任务当前只实施本地代码和测试。下面是后续上线时的核验合同，不表示已经部署。

1. 记录部署前镜像 digest、版本、健康状态与 cline 组 model-usage 的脱敏快照。
2. 按仓库现有镜像发布和服务器备份流程发布固定 sha 镜像，不改其他容器或分组设置。
3. 旧版周期锚点缺少可信来源，升级后应回退近 24h；仍有效的模型冷却必须保持，不因恢复清除而重新尝试已耗尽凭据。
4. 对原 ID 557、558、567 等比较其 fallback 窗口内原始日志/小时聚合与接口合计。不能要求复现本次调查的固定数值，实时 24h 窗口会自然移动。
5. 新发生的默认限流不得产生可信周期；明确额度 reset hint 才可建立下一重置。重置未到时不可清零，到期后按新窗口正常统计。
6. 在缺失用量行检查两套界面的缺失计数、已知 token 与说明。data_complete 仍然只表示所需边界日志保留完整性。
7. 观察正常用户流量和日志，无需主动发送真实推理请求。不要为验证保存用户请求/响应正文或密钥。

回滚：使用上线前镜像与标准备份流程。旧代码仍会把普通模型冷却当作周期重置，因此回滚后本问题可能再次出现；不要把回滚后的周期显示当作可信历史。用量数据库本次修复不应迁移或补账。
