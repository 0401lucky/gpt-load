# 修复模型用量周期误重置与缺失提示

## Goal

隔离普通冷却与额度周期，兼容旧状态并暴露用量缺失

## Requirements

- 默认冷却、普通限流和 Retry-After 重试提示不得推进额度周期；仅明确额度重置证据可建立周期。
- 旧版无来源证明的周期降级为近 24 小时统计，保留冷却、健康状态和历史用量。
- classic/modern 显示缺失/部分缺失请求数，分别表达日志保留完整性和 token 完整性。
- 检查非流式采集链路，仅修复可复现解析缺陷，不猜测补记 token。

## Acceptance Criteria

- [x] 普通 60 秒冷却反复到期不会排除先前用量，调度冷却仍有效。
- [x] 明确重置证据到期才进入新周期，重复提示不截断当前周期。
- [x] 旧检查点保留冷却和健康状态，窗口退回近 24h；新可信周期可跨重启恢复。
- [x] 两套页面可区分真实零与缺失，三语言、投影、小时桶及边界计数一致。
- [x] 非流式调查结论有证据；未复现解析缺陷，未改采集代码，历史缺失不伪造。
- [x] 相关回归通过，完整等价门禁未全绿；环境限制及具体失败见 research/validation.md。
